# Support

Workout Tracker is maintained on a best-effort basis and has no service-level
agreement. Before asking for help, use the latest default branch, follow the
self-hosting guide, and run `npm run release-check`.

Use GitHub Issues for reproducible bugs and focused feature proposals. Include
sanitized logs, the tested commit, runtime versions, and expected versus actual
behavior. Do not post credentials, Athlete data, bearer URLs, production IDs,
FIT files, or private receipts.

Configuration questions that are specific to a Cloudflare account may need to
be resolved with Cloudflare support. Medical, training-program, and exercise
safety advice are outside this project's support boundary. Security issues
must follow [SECURITY.md](SECURITY.md), not the public issue tracker.
